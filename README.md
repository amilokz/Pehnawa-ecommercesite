# Pehnawa — Seasonal Fashion E-Commerce

Online clothing and footwear store for Pakistan. Seasonal collections
(Winter, Summer, Autumn, Spring), PKR pricing, Cash on Delivery,
JazzCash / Easypaisa.

## Live site

`index.html` is the complete store in a single self-contained file —
open it in any browser, or deploy it to any static host
(Vercel, Netlify, GitHub Pages).

## Features

- Cinematic hero matching the campaign reference
- Four seasonal collection cards, each with its own photography
- Trending Seasonal Picks with discounts, ratings and wishlist
- Seasonal + category filters, search and sort
- Working shopping bag with order-summary copy
- Seller waitlist (marketplace feature coming later)
- Light / dark theme toggle, fully responsive
